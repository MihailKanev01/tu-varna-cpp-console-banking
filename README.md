# Console Banking

A C++ console application that explores banking-related logic and object-oriented programming.

## Overview

The repository contains a Visual Studio solution and a C++ implementation. It is intended as a learning project for structuring a command-line application, handling user input and representing banking workflows in code.

## Technology

- **Language:** C++
- **IDE / build system:** Visual Studio
- **Solution:** `Banking.sln`
- **Implementation:** `Banking/Banking.cpp`

## Run Locally

1. Install Visual Studio with the **Desktop development with C++** workload.
2. Clone the repository:
   ```bash
   git clone https://github.com/MihailKanev01/tu-varna-cpp-console-banking.git
   ```
3. Open `Banking.sln`.
4. Select a suitable build configuration and platform.
5. Build the solution, then run the application.

## Project Status

An educational console application. It is not intended for real financial transactions or storing sensitive banking data.
